# American Chairs (proof of concept)

A retro, 1997-style website for an American-owned retailer of heavy-duty,
American-made office, task and gaming chairs. It's a proof of concept to show
manufacturers when applying to become an authorized dealer. It takes no orders.

Hosted free on GitHub Pages: https://rossgrantfitness.github.io/americanchairs/

## What's here

| Path | What it is |
|---|---|
| `*.html`, `style.css` | The site. Generated by `tools/build.py`. Don't hand-edit the HTML; edit `build.py` and rebuild. |
| `research/us-made-chair-brands.md` | Research: which chair brands are built in the USA and how realistic it is to become their reseller. |
| `img/retro/` | Flags, banners and buttons, drawn from scratch by `tools/make_retro_assets.py`. |
| `img/stock/` | Creative Commons stock photos (credits in `tools/stock_credits.json` and on the Photo Credits page). |
| `img/chairs/` | AI concept renders from Google Gemini (`tools/gen_chair_images.py`, prompts in `tools/chair_prompts.json`). Until a render exists, the site shows a "Photo Coming Soon" placeholder. |

## Editing

1. Change content or settings at the top of `tools/build.py`: `SITE_NAME`, `CONTACT_EMAIL`, `CONTACT_PHONE`, the `CHAIRS` list and so on.
2. Run `python3 tools/build.py`.
3. Commit and push. GitHub Pages updates within a minute or two.

## Regenerating the AI chair images

```bash
GEMINI_API_KEY=your-key python3 tools/gen_chair_images.py
```

```bash
python3 tools/build.py
```

The renders are illustrations, not product photos, and the site labels them that
way. Swap in each manufacturer's official dealer photography once you're approved.

## Before going live for real

- Fill in `CONTACT_EMAIL` and `CONTACT_PHONE`.
- Remove `robots.txt` and the `noindex` meta tag in `build.py` when you want search engines to find the site. They're on now so the proof of concept stays out of search results.
- Replace AI renders with official photos, and confirm each chair's exact country-of-origin wording with the maker.
- Have the return policy reviewed so it matches each manufacturer's terms and your state's disclosure rules.
